# UX Decision Log

## 1. On every interection items (buttons, tool tips on setting options, etc.), let the user know what is about to happen

## 2. AVOID COMPLICATED WORDS!

## 3. In the Figma layout, add a button (or a navigation menu in the header) that allow(s) a user to jump between the pages of the webapp

## 4. Make sure that your figma layout is consistent in design

## 5. Prevent "high-cost" errors first.
* Make sure you provide a good default interface for the user

## 6. Make your UI "recognizable." Make the user memorize as less as possible in your interface (i.e: let it be intuitive for them).

## 7. Conside implementing shortcuts to setting filters when searching a video

## 8. Make the design show only what it really does. (make sure that icons properly relate to user's interactions and goals of such interactions)

## 9. Make sure your error messages are written in a clear language. (bold, red text; what went wrong; offer a solution)

## 10. Consider create a "help" page for the product and make sure to explain to the user how to use the app.
* It might also be a good idea to add to "Content Policy" page, stating what Antitube considers as "good" (not distractive) content and "bad" (distractive) content
